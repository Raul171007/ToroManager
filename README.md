# 🐂 ToroManager

Aplicación web de gestión taurina desarrollada con PHP y MySQL.
Demo online disponible en: https://toromanager.42web.io/

## Tecnologías
- PHP
- MySQL
- HTML/CSS
- XAMPP (entorno local)
- InfinityFree (hosting)

## Funcionalidades
- Sistema de login y registro con contraseña cifrada (bcrypt)
- Gestión completa de corridas, toreros, toros, ganaderías y plazas
- Base de datos con datos reales de la temporada taurina 2024
- CRUD completo con relaciones entre tablas
- Control de acceso por sesiones

## Instalación en local
1. Clona el repositorio
2. Importa el archivo `.sql` en phpMyAdmin
3. Configura los datos de conexión en `conexion.php`
4. Lanza con XAMPP y accede desde `localhost`

## Base de datos
Incluye datos reales verificados de San Isidro 2024:
- Toreros del escalafón 2024 (Roca Rey, Talavante, Daniel Luque...)
- Ganaderías reales (Victorino Martín, Núñez del Cuvillo...)
- Plazas reales (Las Ventas, La Maestranza, Pamplona...)
